# Essential links

All URLs below were checked against the public pages on 2026-11-26. The official documentation is the starting point for current commands; this Lab pins version 1.4.5, so newer docs may describe later behavior.

- [Spec Kit documentation home](https://github.github.com/spec-kit/): process choices, core concepts, and navigation to the current guides.
- [Spec-driven development quickstart](https://github.github.com/spec-kit/quickstart.html): recommended phase order and a worked feature walkthrough. Its examples use Copilot syntax; use the Codex form in this Lab.
- [Installation guide](https://github.github.com/spec-kit/installation.html): supported install routes, prerequisites, version check, and initialization options.
- [Codex integration guide](https://github.github.com/spec-kit/integrations/codex.html): `codex` integration key, installed skill path, and `$speckit-*` invocation syntax.
- [Agentic SDD reference](https://github.github.com/spec-kit/reference/agentic-sdd.html): what constitution, specify, plan, tasks, implement, analyze, and converge each do.
- [Understand SDD](https://github.github.com/spec-kit/how-to/sdd.html): the reasoning behind intent-first, multi-step development and its boundaries.
- [Evolve specifications](https://github.github.com/spec-kit/how-to/evolving-specs.html): how to revise an existing feature and reconcile downstream artifacts. Especially relevant to the Lab exercise.
- [Persist specifications](https://github.github.com/spec-kit/how-to/persisting-specs.html): options for retaining and maintaining artifacts after delivery.
- [PyPI package page](https://pypi.org/project/specify-cli/): published `specify-cli` package and release information; use the pinned release in the README for reproducibility.
